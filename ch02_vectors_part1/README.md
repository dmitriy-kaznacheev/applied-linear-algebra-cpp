## Тесты

Тесты библиотеки — в `tests/test_ch02.cpp`. Покрывают все функции, включая граничные случаи (нулевой вектор, несовпадение размеров, коллинеарность, отрицательный модуль).

## Визуализация

Примеры и упражнения с графиками используют `gnuplot-iostream` и открывают интерактивное окно `qt` во время выполнения. Окно остаётся открытым до закрытия вручную.

**Требования:** gnuplot с терминалом `qt` (или `wxt`, `x11`). Проверить: `gnuplot -e "set terminal"` — в списке должен быть `qt`.

**В CI** примеры с графиками не запускаются — только собираются, потому что в GitHub Actions нет дисплея.
